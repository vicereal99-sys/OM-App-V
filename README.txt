OM-Katalog Web-App-Paket

GitHub Pages:
1. Alle Dateien aus diesem ZIP direkt in das Repository "OM-Katalog" hochladen.
2. index.html muss im Hauptverzeichnis liegen.
3. GitHub Pages verwenden/aktivieren.
4. Danach die GitHub-Pages-Seite am Handy öffnen.
5. Android/Chrome: Menü > Zum Startbildschirm hinzufügen / App installieren.

Enthalten:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

Nach dem ersten erfolgreichen Laden ist die App auch offline nutzbar.
